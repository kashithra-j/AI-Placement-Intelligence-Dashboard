# AI Placement Intelligence Dashboard

An interactive Power BI dashboard designed to analyze student academic performance, placement trends, technical skills, and AI-based placement predictions.

## Project Overview

The AI Placement Intelligence Dashboard provides data-driven insights into student placement performance. It helps analyze academic qualifications, student skill proficiency, company-wise recruitment patterns, and predicted placement probabilities through interactive visualizations.

## Objectives

- Analyze student placement trends across different branches.
- Understand the relationship between CGPA and placement packages.
- Evaluate student technical and soft skills.
- Analyze company-wise recruitment patterns.
- Visualize AI-based placement predictions and probabilities.
- Support data-driven placement preparation and decision-making.

## How to Use

1. Clone or download this repository.
2. Download the Power BI `.pbix` file.
3. Open the file using Microsoft Power BI Desktop.
4. Configure the dataset source if necessary.
5. Refresh the data if the source is available.
6. Explore the dashboard using its interactive filters and visualizations.
