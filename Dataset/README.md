# Dataset

This folder contains the dataset used to develop the AI Placement Intelligence Dashboard.

## Dataset Information

The dataset includes:

- Student academic information
- CGPA scores
- Branch details
- Placement-related information
- Company and package details
- Placement percentage
- AI prediction and probability
- Technical skills such as Python, SQL, Java, and DSA
- Soft skills such as Communication and Aptitude

## Purpose

The dataset is used to analyze student academic performance, placement trends, and skill proficiency.

**Note:** Only publicly shareable or anonymized data should be uploaded.
