# Project Overview

## AI Placement Intelligence Dashboard

### About the Project
The AI Placement Intelligence Dashboard is a Power BI project designed to analyze student placement-related data, academic performance, skills, and placement predictions.

### Project Objectives
- Analyze student placement information.
- Understand placement trends across different branches.
- Study the relationship between CGPA and placement packages.
- Analyze student technical and soft skills.
- Present placement probability and prediction results.

### Tools Used
- Microsoft Power BI
- Power Query
- GitHub

### Key Dashboard Analysis
- Placement analysis by branch
- Average package by company
- CGPA distribution
- Student skill analysis
- Placement probability and prediction analysis

### Project Outcome
This dashboard provides an interactive way to explore student placement data and understand patterns that may support placement-related decision-making.
